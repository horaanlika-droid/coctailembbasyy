# Cocktail Embassy

Витрина барного стекла в стиле Telegram Mini App: каталог, корзина, заказы, счёт для юрлица, поддержка и Telegram-бот.

## Быстрый старт

```bash
npm install
cp .env.example .env
npm start
```

Откройте `http://localhost:3000`. В режиме предпросмотра (без `BOT_TOKEN`) приложение запускается без Telegram авторизации.

### Переменные окружения

Для запуска на BotHost достаточно добавить только:

- `BOT_TOKEN` — токен бота из @BotFather;
- `ADMIN_IDS` — Telegram ID администраторов через запятую.

Все интеграции оплаты необязательны и подключаются позже: `PUBLIC_URL`, `YUKASSA_SHOP_ID`, `YUKASSA_SECRET_KEY`. До добавления ключей можно принимать заказы и счета для юрлиц, а ЮKassa подключить без изменения кода.

## Возможности

- адаптивная iOS-подобная витрина с каталогом из `data/catalog.json`;
- категории, поиск, сортировка, избранное, карточки товаров;
- корзина с бесплатной доставкой от 10 000 ₽;
- оформление с курьером, самовывозом и СДЭК/ПЭК;
- онлайн-оплата через точку расширения ЮKassa и счёт A4 `/invoice/:id`;
- заказы клиента, чат поддержки и уведомления администраторов;
- команды бота `/start`, `/catalog`, `/admin`;
- JSON-хранилище с атомарной заменой в `data/db.json` (файл не публикуется в git).

## Обновление каталога

Прайс хранится в репозитории. Скрипт `scripts/build_catalog.py` является точкой входа для обработки нового PDF; при наличии PyMuPDF/Pillow/Numpy его можно расширить для автоматического извлечения позиций и изображений:

```bash
python3 scripts/build_catalog.py новый-прайс.pdf
```

Изображения товаров лежат в `webapp/assets/products/`.
